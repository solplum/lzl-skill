# lzl-private

管理用户明确交给本技能的资料与凭据。普通资料保存在独立的本地资料库，密钥保存在系统凭据库；默认不写入 AI 长期记忆。

脚本入口是本技能目录下的 `scripts/private_vault.py`。先取得当前安装目录的绝对路径，使用 Python 3.10+ 运行脚本；路径含空格时正确引用。普通资料不需要额外 Python 依赖，密钥功能的依赖与系统配置见 [README.md](README.md#密钥功能)。

## 首次使用与存储位置

1. 运行 `discover`，只检查已有配置、已记录路径和系统默认位置。使用返回结果，不扫描整个磁盘、不读取资料正文或真实密钥。
2. 已有有效配置时沿用其 `configured_path`。配置损坏、资料库丢失或目录无权访问时，说明实际问题及路径，先修复配置或还原资料后再继续；`init` 不会通过新建空库绕过这些错误。
3. 尚未配置时，提供简短的选择引导：
   - **系统默认目录（推荐）**：展示 `default_path` 的完整绝对路径，说明选择后会创建或复用资料库。
   - **自己指定目录**：让用户提供绝对路径。
   - **使用已有资料库**：仅在 `existing_vaults` 检测到有效资料库时显示，列出每个目录的完整绝对路径供选择。没有检测到时省略这一项。
4. 等待用户选择后执行 `init` 或 `init --path <选定的绝对路径>`。自定义目录必须为空或已有有效资料库，后者自动复用。报告最终资料目录和本机配置文件的绝对路径。

所有面向用户的存储位置都使用当前机器解析出的完整绝对路径，不能只显示 `~`、环境变量、相对路径或“系统默认目录”。不写死示例用户名。后续使用直接沿用配置，无须反复询问位置。

资料与配置必须独立于技能安装目录和 Git 工作区，脚本会拒绝这些位置。有效配置下，用户明确要求切换位置时可用 `init --path` 重新绑定，保留旧库且不自动迁移数据。升级技能只更新安装文件；复制资料目录到另一台机器不会同时迁移系统凭据，需重新录入。

隔离测试或单独配置可使用全局参数 `--config <绝对路径>`，放在子命令前；后续命令沿用同一配置路径。默认配置位置见 [README.md](README.md#首次使用)。

## 记录与查找普通资料

- 记录：先确定简短名称，以及必要的用途、所属项目；用 `put NAME --file <绝对路径>` 或 `put NAME --stdin` 保存普通文本。`--description` 和 `--project` 可补充检索信息。更新时沿用原名称，避免重复记录互相冲突的版本。
- 查找：使用 `list --query <关键词>` 获取匹配条目的元数据，再对当前任务需要的普通资料运行 `show NAME`。避免整库读入上下文。
- 删除：用户要求删除对应条目时运行 `delete NAME`，按实际结果说明。
- 文本若包含 API Key、密码、Token 或私钥，改走下方密钥流程，不存入普通资料正文、说明或名称。

## 录入与使用密钥

1. 使用 `status` 查看系统凭据后端。缺依赖、凭据库锁定或当前系统不支持时，说明原因和设置方法；普通资料仍可使用，密钥操作保持失败，不降级为明文文件。
2. 录入或更新时，让用户在自己的本机交互终端运行 `secret-set NAME`，通过隐藏输入填写。给出的命令包含脚本的实际绝对路径。AI 不代填，不要求用户把密钥贴进聊天、命令参数、普通文件或环境配置。
3. 名称、用途和所属项目可以进入资料索引，真实值只进入系统凭据库。`show NAME` 对密钥条目仅返回元数据。
4. 用户要求使用已保存凭据时，先匹配名称和项目，必要时澄清同名服务的环境。运行 `run NAME --env ENV_NAME -- COMMAND...`，将密钥临时注入该本地子进程。仅执行当前任务授权的命令和访问。
5. 按实际执行状态报告结果。删除密钥条目时，`delete NAME` 同时处理系统凭据与索引；出错时保留错误事实，不宣称成功。

密钥使用前先检查目标命令的作用，避免调试输出、环境变量转储或不必要的外发。脚本会对输出中的精确密钥字符串打码；编码、拆分或程序自行外发的内容不在这一保护范围内。

本技能提供操作约定和减少暴露的机制，不提供针对任意本机命令权限的安全隔离。普通资料库也未加密：只有需要参与当前任务的普通资料才交给模型读取。

## 完成标准

保存、修改、删除和执行均以脚本返回的结果为准。回答只包含本次操作结果、必要的元数据与绝对路径，保持密钥原文不进入回复、日志或公开仓库。
